# 像素小飞猫

## 造型与动作

角色采用像素风格，保留「勇敢小飞猫」的利落侧身、朝前看的眼神、前伸的奶油色爪尖与迎风红披风。琥珀橘、奶油白、深青色眼睛和深紫棕外轮廓组成有限色板；额头与尾巴保留少量条纹。原稿按 2 个世界单位一格手工绘制，只用水平、垂直色块，没有平滑曲线、渐变或细描边。

巡航前爪领飞、后腿向后收；起飞伸爪、下落张爪和睁眼、撞击耷耳翻肚皮。红披风使用两帧像素画，方向跟随飞行速度，尾巴稍晚跟随。暂停冻结所有动作，重开恢复姿态；减少动态效果模式关闭拉伸、披风换帧和连续翻转。

## 实施与验收标准

1. **造型**：在实际游戏尺寸和放大预览中检查六种姿态。面部清楚、前后肢可辨，剪影能看出飞行方向；旋转和拉伸后仍是有限色块与硬像素边缘。
2. **绘制**：玩家与幽灵轮廓一致，整只幽灵统一着色与半透明，四肢重叠不叠深；极限姿态不裁切，实际 13 像素碰撞圆位于实体造型内。
3. **流程**：验证素材加载失败与重载、起飞、下落、碰撞、重开、暂停和五只幽灵同屏；同步应用图标、角色预览和游戏截图。

本次范围是角色、动画绘制与衍生素材。物理、碰撞半径、关卡、得分、录像格式和场景布局保持原样。

## 素材与绘制

原稿在 `src/assets/cat.svg`。SVG（可缩放矢量图形）在这里只作为可编辑的像素图集容器：4×4 个图层单元，实际载入为 192×160 像素。角色在 `src/render/cat.ts` 的 72×72 离屏画布中完成关节、整体旋转和拉伸，再用最近邻采样放大（直接复制像素、不混色）。各图层按目标像素中心取最近的原稿像素，直接复用像素缓冲区，避免浏览器旋转取样产生半透明边缘。玩家与幽灵共用合成路径；加载时裁去图层空白，帧循环内不解码素材、读取画布像素或创建画布。动作驱动在 `src/render/animator.ts`。

开发服务器的 `/tools/gallery.html` 展示实际绘制；加 `?sky=22` 检查夜景，加 `?debug` 检查碰撞圆。`npm run art-assets` 从游戏绘制结果导出像素应用图标以及 `docs/character.png`、`docs/preview.png`，避免图标退回平滑风格。

- 100 项单测通过；类型检查与生产构建通过。
