## 参考与取舍

实际打开了 <https://senzan.nosuchfield.com/>（页面构建标记 `049b382`），检查开始菜单与玩法速查。借鉴清晰的开始入口、可随时查阅的操作说明、明确目标、短反馈循环；不移植战斗玩法、庞大模式菜单、后端排行榜或全新美术风格。

现有问题：

1. “再来一次”实际上仅回到开始页，需要第二次操作才能起飞。
2. 星星没有解释分数门槛；滑翔能量耗尽、小鱼干用途及失败后的改进方向不够明显。
3. Space 在聚焦按钮时被全局起飞截获；分享防误触仅限 CSS 指针，键盘仍可绕过；切后台发生在恢复倒计时期间不能取消恢复。
4. 暂停背景仍逐帧重绘；失焦手柄仍可能产生动作。输入解绑未清理 hold。
5. 部署流水线不运行浏览器交互检查。
